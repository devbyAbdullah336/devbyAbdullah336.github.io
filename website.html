Web Development Journey

Click a week to expand and explore progress.

Week 1 — Basic Web Page

In Week 1, I created a basic web page with a title and subtitle. I also added buttons (non-functional at this stage) and implemented a simple gradient background. This will later be replaced with a game-based visual for a more immersive look.

Week 2 — Improving Website Visuals

In Week 2, I focused on improving the overall visual quality of the site. This included better gradients, hover effects, and cleaner styling using CSS to make the website feel more polished and professional.

Week 3/4 — Functionality & Progress System

In Week 3, I refined button positioning, improved hover effects, and enhanced the overall UI design. In Week 4, I introduced functional navigation and built expandable progress cards, allowing users to view weekly updates with images, videos, and descriptions.

Week 5/6 — Credits System

In Weeks 5 and 6, I will implement a fully functional Credits section, detailing resources, tools, and inspirations used throughout the project.
