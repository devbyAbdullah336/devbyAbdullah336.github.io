Why Game Development for Capstone?

For my capstone project, I wanted a challenge that merged deep technical programming with creative design. I chose to build SoulsArena, a third-person combat prototype in Unreal Engine 5, because it allowed me to push my problem-solving limits.

Developing a game from scratch requires balancing complex logic structures—like custom AI behavior trees, motion-warped free-flow combat mechanics, and fluid animation state machines. This project represents my core dedication to continuous technical growth, achievement, and turning highly ambitious ideas into working reality.
