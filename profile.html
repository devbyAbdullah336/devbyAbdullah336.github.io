Why Game Development?

When it came time to pick a Capstone project, I knew I didn't want to just write a standard research paper or build a basic website. I wanted to choose something that would actually challenge me and make me a better programmer. Game Development was the perfect choice because it forces you to figure out everything all at once—logic, physics, art, and user interface.

Building SoulsArena has taught me that making a game is way harder than just playing one. You have to build the entire world from absolute zero. To make a playable prototype, I've had to learn how to deal with real-time mechanics like character hitboxes, programming enemy AI to react to the player, and making sure the controls feel smooth and responsive.

At the end of the day, this capstone project is proof of my coding journey. It's about sitting down, breaking things, spending hours troubleshooting why a script isn't working, and finally getting to see your own ideas come to life on the screen.

What is Game Development anyway?

To me, game development isn't just about sitting down and writing lines of code. It’s basically where math, logic, art, and sound all crash together to make something interactive. You aren't just telling a computer to display static text or process information; you are creating an entire living environment with its own set of rules.

Every time a character jumps, swings a weapon, or takes damage, there are dozens of calculations happening under the hood to make sure it looks right and feels satisfying to play.

My Goals for this Project

When I started working on SoulsArena, my main goal was to move past basic tutorial code and actually build a working, round-based combat system completely by myself.

I wanted to prove that I could handle complex tasks like coding scaling enemy AI that gets progressively tougher each round, setting up accurate hit registration, and designing a clean user interface that keeps track of player stats without breaking. I didn't need it to look like a multi-million dollar studio game—I just wanted it to be polished, responsive, and genuinely fun to test.

Where I'm Heading Next

This capstone project is just the beginning for me. After completing Grade 11 and wrapping up this version of SoulsArena, I want to start diving deeper into complex game engines like Unity or Unreal Engine, and learn more about advanced programming concepts like spatial partitioning and object-oriented architectures.

My ultimate goal is to keep building bigger, more detailed indie games, get a degree in Computer Science, and eventually break into the gaming industry as a software engineer.
