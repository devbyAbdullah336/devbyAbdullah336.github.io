Why Game Development?

When choosing a focus for my Capstone project, I wanted to pursue a discipline that wouldn't just challenge my programming knowledge, but completely stretch it. Game Development emerged as the perfect domain, sitting precisely at the crossroads of complex system logic, physics implementations, and front-end interface engineering.

Building SoulsArena requires far more than arranging visual assets—it demands designing an entire underlying framework from nothing. Pushing this concept into a functional prototype means solving rigorous real-time mechanics. Managing modular blueprint arrays, precise vector calculations for directional hit responses, and detailed AI behavior tree state changes forces an absolute commitment to solid software engineering basics.

Ultimately, this capstone stands as practical, working proof of my technical journey. It is a testament to working through system bottlenecks, structuring scalable frameworks, and executing a vision from the initial blueprint layout down to the final viewport layer.
